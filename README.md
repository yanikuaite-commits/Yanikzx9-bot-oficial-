# Nano Bot 🤖

Bot avançado para WhatsApp com IA, gestão de grupos, downloads e muito mais!

## ✨ Funcionalidades

- **Gestão de Grupos VIP** (Ouro, Diamante, Lenda)
- **IA Integrada** (Groq API) - Respostas inteligentes
- **Sistema de Pagamentos** (E-Mola/M-Pesa)
- **Downloads**: TikTok, Instagram, YouTube (vídeo/áudio)
- **Moderação**: Anti-link, palavras banidas, auto-delete
- **Stickers**: Criação de stickers a partir de imagens/vídeos/texto
- **Boas-vindas Personalizadas** com cartão de imagem
- **Tradutor** de texto
- **Sistema de Atalhos e Lembretes**
- **Estatísticas e Relatórios** completos
- **RAM otimizada** com cache e limpeza automática

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Configurar variáveis de ambiente
cp .env.example .env
# Editar .env com sua GROQ_API_KEY

# Iniciar o bot
npm start
